# IKEA-Customer-Segmentation-and-Revenue-Analytics-Dashboard

An end-to-end data analytics project that takes raw transactional mock data from Excel through **PostgreSQL**, **Python (Pandas)** and **Power BI** to produce an interactive dashboard for tracking customers, revenue, churn and RFM-based customer segments.
<br>
<br>

All data used here is MOCK DATA for learning purposes and DOES NOT represent IKEA's actual customers, sales, or business performance.

## 🎯 Project Objective
 
To understand **who the customers are, how much revenue they generate, and who is likely to leave**, by:
 
- Segmenting customers using **RFM (Recency, Frequency, Monetary)** scoring.
- Tracking revenue trends across months, quarters, and years.
- Measuring churn and identifying at-risk customers.
- Comparing performance across countries.

<br>

## 🛠️ Tech Stack
 
| Stage | Tool |
|-------|------|
| Raw data | Microsoft Excel |
| Database & data preparation | PostgreSQL |
| Data cleaning | Python (pandas) in Jupyter Notebook |
| Visualisation | Power BI (DAX, slicers, interactive charts) |
